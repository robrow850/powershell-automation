# Fictional normalized datasets

Every identity and resource in these fixtures is invented. These are lab schemas,
not raw Graph, AD or Exchange responses. See the JSON field names as the schema:
arrays represent users, plans or members; health values are boolean or null.
Group IDs and user IDs must be unique. Null health evidence remains Unknown.
Production collectors, schema migration, tenant permissions and real policy thresholds
must be designed and tested separately.
